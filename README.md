# Padronização dos Commits:
## Depois de ter criado uma nova branch com o nome do ticket, o modelo da mensagem deve ser o seguinte:

* feat/BRANCH: Featura X adicionada;
* fix/BRANCH: Correção de X função;
* bug/BRANCH: Correção de bug em X;
* Add mais caso necessário


# Como utilizar:
Clone o Repositório na sua IDE de preferência, e rode no terminal:
```
npm install
```
